# Happy Wheels portable capture

The game assets and launcher are static. The page markup, styles, and launcher logic live in `index.html`, `index.css`, and `index.js`; `bg.webp` fills the letterboxed page area at 25% opacity. The sign-in button image is local at `img/login_w.png`. VS Code Live Preview or GitHub Pages can serve the folder without `serve.py`; online login and game API calls use the dedicated Cloudflare Worker at `https://tjfcors.coolsite.cv`.

The app uses the deployed Worker from GitHub Pages and VS Code Live Preview. To test a local Worker instead, run `wrangler dev --config "C:\Users\Admin\Documents\GitHub\cv003.github.io\.claude\workers\tjfcors.wrangler.jsonc" --port 8787 --var "TJF_SESSION_SECRET:<random-secret-at-least-32-bytes>"` and add `?tjf_worker=local` to the loopback preview URL. That override is accepted only on localhost/loopback. Add any non-loopback preview origin to the Worker allowlist before using it.

Deploy the Worker separately from the static site. Its Wrangler configuration binds it to `tjfcors.coolsite.cv`; set the required `TJF_SESSION_SECRET` with `wrangler secret put TJF_SESSION_SECRET --config "C:\Users\Admin\Documents\GitHub\cv003.github.io\.claude\workers\tjfcors.wrangler.jsonc"` before deployment. The secret must be a random value of at least 32 bytes and must not be committed or shared with the page.

The game opens on a black, fullscreen canvas. Use the in-game **Sign in** control to authenticate without leaving the page; it changes to **Sign out** after authentication. The Worker sends credentials only to Totaljerkface's fixed login endpoint and keeps the upstream cookies encrypted inside a short-lived bearer token; game scripts never receive the upstream cookies. The token stays in tab-scoped session storage and expires after six hours. Only `.hw` game API routes are proxied; analytics and arbitrary proxy destinations are not supported.

The Worker accepts the production site origins and local loopback preview origins only. It is deployed at `https://tjfcors.coolsite.cv` and `https://tjfcors.cvowot.workers.dev` with `TJF_SESSION_SECRET` configured.
